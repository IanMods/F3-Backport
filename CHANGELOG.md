# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.1.0] - 2026-10-05

### Added

- Added config options to edit all currently available debug entries
- Added a config screen
    - Default keybind is "Delete"
    - Currently only has a handful of options, but will eventually have all of them
        - The remaining options can still be changed using the config file
- Added a "debugGuiScale" option, separate from the Minecraft gui scale
    - Set to -1 to follow the Minecraft gui scale
